# Yuji Wang · Homepage

Source of [voyagewang.github.io](https://voyagewang.github.io), built with React and Vite on the
[Anleeno Academic](https://github.com/Anleeno/anleeno-academic) template (MIT).

- Edit content in `config/*.json` (see [`config/README.md`](config/README.md)); images live in `src/assets/`.
- Files in `public/` are served as-is at the site root, e.g. `public/ECCV_2026_cr_1-3.pdf` → `/ECCV_2026_cr_1-3.pdf`.
- `npm install`, `npm run dev` to preview; pushing to `master` builds and deploys through GitHub Actions.

The previous Jekyll site is kept at the git tag `jekyll-backup`.
